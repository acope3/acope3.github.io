This website is built with [Jekyll](https://jekyllrb.com/) and hosted on [GitHub Pages](https://pages.github.com/).

It is adapted from [blotter](https://github.com/blab/blotter), the open-source (MIT-licensed) template written by [Trevor Bedford](https://bedford.io/) for the Bedford lab website. I found it via [Premal Shah's](https://theshahlab.org/) website, which uses the same template. Detailed instructions on building a site from this template can be found [here](https://bedford.io/misc/about/).
